# Yerin mobil UI V2

Bu klasör, Yerin web projesinin renk dağılımı mobil arayüze uyarlanarak hazırlanmış 23 ekran görselini içerir.

- Ana zemin: `#F5F9F8`
- Kartlar ve form alanları: `#FFFFFF`
- Seçili alanlar ve küçük vurgular: `#C2FCF7`, `#C9FBFF`
- Grafik ve ikincil vurgu: `#85BDBF`
- İkincil metin: `#57737A`
- Ana metin ve buton: `#040F0F`
- Font: Manrope

`index.html`, tüm isimlendirilmiş PNG dosyalarını tek galeri içinde gösterir.
